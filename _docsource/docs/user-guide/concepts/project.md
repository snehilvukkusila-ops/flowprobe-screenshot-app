## What it is

The **Projects** screen shows the list of projects in a table with project, owner, status, and deadline information.

You can filter the list with a search input that has the placeholder `Filter projects`.

![The Projects screen. Some form field values are hidden for privacy.](/screenshots/flowprobe-screenshot-app-projects-1/0.png)

## Where to find it

Open `/flowprobe-screenshot-app/projects`.

## On this screen

- **Project**
- **Owner**
- **Status**
- **Deadline**

## Fields

| Field | Type | Required |
| --- | --- | --- |
| **Filter projects** | search | no |
