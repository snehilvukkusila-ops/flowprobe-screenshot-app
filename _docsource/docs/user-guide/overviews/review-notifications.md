## What it is

Review Notifications is the notifications feature of the application.

The **Review Notifications** screen shows status badges, such as `Unread` and `Read`, and provides a **Mark all read** control and action.

## Where to find it

Open `/flowprobe-screenshot-app/notifications`.

## Get started

Start with [Mark all read](../tasks/mark-all-read.md).

This statement could not be confirmed against the project's own sources. Treat it as unverified.
